# Долой уныние — лендинг

Одностраничный сайт-фильм для мероприятий «Долой уныние» (Санкт-Петербург).
Сайт устроен как короткометражный фильм, которым зритель управляет скроллом:
ночной пролог → pinned-исповедь → зум-раскрытие толпы → команда → разгон →
**крик** (видео растёт из вклейки в fullscreen) → выдох → автор → регистрация → титр.

Стек v2: Vite + TypeScript + GSAP ScrollTrigger + Lenis + Three.js
(шейдерная атмосфера с зерном, дисторшн-планы фотографий; lazy-чанк
~131KB gzip грузится только на способных устройствах, initial ~53KB).
Ревизии дизайн-законов относительно DESIGN-LANGUAGE — в `REDESIGN-NOTES.md`.

## Запуск

```bash
npm install
npm run dev        # dev-сервер (http://localhost:5173)
npm run build      # проверка типов + прод-сборка в dist/
npm run preview    # локальный просмотр прод-сборки
npm run media      # пересборка медиа из assets/ в public/media/ (нужен ffmpeg)
```

Debug-режим: добавьте `?debug=1` к URL — в консоль пойдут логи
`[scene] [scroll] [state] [media] [webgl] [climax]`.

## Структура

```
index.html              разметка всех 11 сцен (контент сайта здесь)
src/
  main.ts               порядок загрузки стилей и инициализация модулей
  lib/
    debug.ts            логгер (?debug=1)
    state.ts            состояния страницы night→day→after (необратимы)
    motion.ts           Lenis + ScrollTrigger, pinScene-хелпер
    split.ts            сплиттер текста (chars/words/lines, a11y)
    choreography.ts     реверлы блоков и посимвольные титры
    marquee.ts          бегущие строки (скорость дышит от velocity)
    climax.ts           кульминация: удары 3.4/4.7с, звук, эхо-цикл, поп-луп
    scenes/             pinned-сцены: prologue, door, buildup, scream, finale
    sound-consent.ts    согласие на звук (сцена 4½)
    degradation.ts      порядок загрузки, тихие ошибки медиа
    webgl/atmosphere.ts шейдерный фон: градиент+зерно, волна крика (lazy)
    webgl/photos.ts     дисторшн-планы фотографий (velocity/hover)
  styles/
    tokens.css          палитра, такт, паузы, тень (имена цветов — из DESIGN-LANGUAGE)
    typography.css      6 ступеней шкалы громкости (ШЁПОТ…КРИК)
    base.css            reset, слои, наклейки, фокус
    scenes/*.css        по файлу на сцену
scripts/prepare-media.sh  конвертация видео/фото (ffmpeg)
assets/                 исходники фото и видео (не выкладываются)
public/media/           подготовленные медиа (генерируются скриптом)
```

## Как обновлять контент

- **Даты расписания** — в `index.html`, сцена 8 (`s8-dates`). Помечены TODO —
  проверять перед каждым релизом.
- **Тексты** — в `index.html`; каждая строка должна проходить «тест голоса»:
  звучит ли она как живая речь Ильи (см. `DESIGN-LANGUAGE.md`, §20).
- **Новые фото/видео** — положить в `assets/`, добавить обработку в
  `scripts/prepare-media.sh`, прогнать `npm run media`. Правила отбора и
  кадрирования — `DESIGN-LANGUAGE.md` §7–8 и Приложение Ж (лица не режутся,
  одна проявка, видео ≤10 c).
- **Рукописные пометки** — сейчас стоят заглушки (волнистое подчёркивание,
  SVG-знак звука) с TODO в разметке; заменить сканами настоящего маркера.

## Деплой

Статика: `npm run build` → выложить содержимое `dist/` на любой статический
хостинг (Netlify/Vercel/GitHub Pages/nginx). Перед релизом:

1. Проверить даты в сцене 8.
2. Заменить `og:image`/canonical на абсолютные URL боевого домена
   (TODO-метки в `index.html`).
3. Прогнать чек-лист приёмки: `DESIGN-LANGUAGE.md` §24 (10 тестов) и
   страховой минимум `EXPERIENCE-SCRIPT.md` §14.

## Концептуальные документы (источники истины)

1. `RESEARCH.md` — исследование проекта, аудитории и материалов
2. `CREATIVE-DIRECTION.md` — концепция «Репетиция воскресенья», драматургия
3. `ART-DIRECTION.md` — режиссура, посекундная партитура крика
4. `DESIGN-LANGUAGE.md` — визуальная система, 110 правил, паспорта ассетов
5. `EXPERIENCE-SCRIPT.md` — сценарий 11 сцен и мобильная режиссура
6. `REDESIGN-NOTES.md` — ревизии законов v2 (тёмный пролог, заметный моушн, Three.js)
7. `.ai-factory/plans/` — планы реализации (v1 и v2)

Любое изменение сайта сверяется с этими документами; при конфликте
«как выглядит» решает DESIGN-LANGUAGE, «что чувствует» — CREATIVE-DIRECTION.
