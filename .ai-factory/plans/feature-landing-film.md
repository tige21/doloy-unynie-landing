# План: Лендинг-фильм «Долой уныние»

**Ветка:** `feature/landing-film` (база: `main`)
**Создан:** 2026-07-13
**Описание:** Реализация одностраничного лендинга-фильма по пяти концептуальным документам проекта: `RESEARCH.md`, `CREATIVE-DIRECTION.md`, `ART-DIRECTION.md`, `DESIGN-LANGUAGE.md`, `EXPERIENCE-SCRIPT.md`. Сайт — скролл-фильм из 11 сцен («Репетиция воскресенья») с кульминацией-криком, тремя состояниями цвета и строгим дизайн-языком.

## Settings

- **Testing:** no — тесты не пишем (решение пользователя); приёмка — по чек-листам DL 24 и страховому минимуму сценария
- **Logging:** verbose — debug-логгер за флагом `?debug=1` (префиксы `[scene] [scroll] [state] [media] [webgl] [climax]`), no-op в проде без флага
- **Docs:** yes — обязательный докс-чекпоинт в конце (README: запуск, структура, обновление контента, деплой)
- **Stack:** Vite + vanilla TypeScript + GSAP ScrollTrigger; Three.js — опциональный слой с правом на отказ

## Источники истины

Все решения по внешнему виду, текстам и поведению берутся из документов проекта, а не изобретаются:

- Эмоции, тексты, порядок сцен → `EXPERIENCE-SCRIPT.md` (11 сцен, хронометраж, мобильная режиссура §13)
- Посекундная партитура кульминации (удары на 3,4 с и 4,7 с) → `ART-DIRECTION.md` §6
- Цвета, типографика, правила элементов, чек-лист приёмки → `DESIGN-LANGUAGE.md` (палитра 3.2, шкала 4.3, 110 правил, чек-лист 24)
- Паспорта всех фото/видео (что где можно) → `DESIGN-LANGUAGE.md` Приложение Ж
- Тексты FAQ → `RESEARCH.md`

**Страховой минимум (нельзя потерять ни при каких компромиссах):** (1) пауза сцены 4½ перед криком; (2) синхронность типографических ударов с пиками видео 3,4/4,7 с + необратимость цвета; (3) честный проводник регистрации сцены 8 с эхо-видео.

## Риски и заметки

- **Даты расписания** в faq-05 могут устареть — проверка перед релизом обязательна (задача 9, TODO в коде; DL Ж7).
- **Рукопись** — до появления сканов маркера используются временные плейсхолдеры с TODO (DL 4.2: шрифт-скоропись только как заглушка).
- **Синхронизация ударов** — самая тонкая инженерная задача (#11): requestVideoFrameCallback не везде доступен, fallback timeupdate имеет гранулярность ~250 мс — при рассинхроне >100 мс удары привязывать к таймеру от старта воспроизведения.
- **Кадр из «Друзей» (faq-06)** — юридически уязвим; при сомнениях заменяется рукописной пометкой без потери смысла (DL Ж10).
- Ссылка регистрации ведёт на сторонний сайт ПРОСТО — проводник обязан говорить об этом честно и заранее (сценарий, сцена 8).
