# План: Редизайн v2 — «Кинетический фильм» (9/10)

**Ветка:** `feature/landing-v2` (база: `feature/landing-film` — редизайн строится поверх работающей v1)
**Создан:** 2026-07-13
**Причина:** фидбек заказчика на v1 — «очень много пустого пространства, никаких GSAP/Three.js анимаций, дизайн выглядит нелепо». Требуемый уровень: 9/10, awwwards-класс.

## Диагноз v1 (что чиним)

1. **Пустота без атмосферы** — паузы концепции читались как «ничего нет». Лечение: pin+scrub сцены (контент сменяется внутри закреплённого экрана — скролл двигает фильм, а не листает дыры), плотные плакатные развороты, фоновые гигантские слова, marquee.
2. **Невидимый моушн** — «дыхание» v1 неотличимо от отсутствия анимаций. Лечение: кинетическая типографика (посимвольные/построчные реверлы), smooth-scroll (Lenis), параллакс, scrub-зумы, magnetic-hover.
3. **Нет настоящего WebGL** — 2KB-шейдер незаметен по определению. Лечение: Three.js по-взрослому — атмосферный шейдер-фон с зерном, дисторшн-планы фотографий, шейдерная волна крика.
4. **«Зин» выглядел самодельно** — полароиды и волнистые подчёркивания в моём исполнении дешевили. Лечение: смена художественной подачи на тёмный кинематографический стиль (решение заказчика: «тёмный кино-пролог»).

## Решения заказчика

- **Ветка:** новая `feature/landing-v2`, v1 остаётся нетронутой
- **Палитра:** тёмный кино-пролог — уныние = глубокий графит с зерном; крик взрывает в свет и оранжевый; драматургия «уныние → крик → тепло» сохраняется
- **Моушн:** максимум — pin+scrub, Lenis, кинетическая типографика, marquee, Three.js фон + дисторшн фото, рост видео из вклейки в fullscreen

## Ревизия дизайн-законов (фиксируется в REDESIGN-NOTES.md)

Заказчик — высшая инстанция (DL 25: конфликты решает владелец). Пересматриваются: запрет тёмных фонов (пролог теперь ночной), «движение только незаметное» (теперь моушн — часть зрелища), запрет smooth-scroll (Lenis разрешён), запрет текста на фото (разрешены оверлеи с градиентной подложкой), «WebGL нельзя увидеть» (теперь можно и нужно). ## Риски

- **Pin+scrub на мобильном** — капризная зона (адресная задача #27; при дёрганьях — упрощение без потери плотности).
- **Lenis + ScrollTrigger + pin** — известные тонкости синхронизации; интеграция строго по официальному рецепту (задача #18).
- **Дисторшн лиц** — эффект не должен уродовать людей (закон «лица неприкосновенны» остаётся): волна деликатная, в покое фото честное.
- **Перфоманс three + дисторшн на слабых устройствах** — феатур-детект и самоотключение из v1 переносятся на новый слой.
- **Синхронизация ударов при pin-росте видео** — воспроизведение стартует только после достижения fullscreen, механика v1 не переписывается, а оборачивается.
